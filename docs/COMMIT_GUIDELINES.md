# Commit guidelines

This repo is public. Keep commits and file content free of editor-specific or AI-assistant metadata.

## Do not commit

- `.cursor/` or any editor-only config directories
- Plan files, agent transcripts, or chat exports
- `Co-authored-by:` trailers naming tools or assistants
- Comments like "generated by …" or "written with …" in source code
- Log dumps from local debugging sessions

## Before you push

Run the hygiene check from the repo root:

```bash
./scripts/check-repo-hygiene.sh
```

Install an optional pre-commit hook (blocks commits that fail the check):

```bash
./scripts/install-git-hooks.sh
```

## Commit messages

- Describe **what changed** and **why** in your own words
- Use the imperative mood (`Add cart API`, `Fix ALB routing`)
- No tool signatures, emojis, or boilerplate from assistants

## If something slipped through

1. Remove the offending lines or files
2. Re-run `./scripts/check-repo-hygiene.sh`
3. Amend or add a follow-up commit before pushing
